# Create a token

Prepare the identity, choose the settings, and review your token before creating it.

## Before you start

Open Create and connect the wallet you intend to use as the creator. The form checks
that your wallet is connected to Arc before you can continue.

Have your token image and any website or social links ready. The preview updates as
you enter your details, so you can check how the token will appear.

## Give it an identity

| Field | What to enter |
|---|---|
| Name | 2–32 characters. Use the name you want people to see. |
| Ticker | 2–10 letters or numbers. The form converts letters to uppercase. |
| Image | PNG, JPG, GIF or WebP. Use the crop tool to frame the image; the final image must be 4 MB or smaller. |
| Description | Optional. Up to 280 characters. |
| Links | Optional website, X and Telegram links. Check each destination before continuing. |

## Choose the tax settings

Start with a preset or choose Custom. Buy and sell tax can each be set from **1% to
10%**. The two rates can be different.

Divide the allocation between creator funds, buyback and burn, dividends, and
liquidity. These four percentages must add up to exactly 100%. Argus's share is taken
before this allocation is applied (see [`05-fees-and-rewards.md`](05-fees-and-rewards.md)).

> **Review these settings carefully.** Tax rates and allocation cannot be changed
> after launch. Check them before confirming.

## Decide on a dev buy

A dev buy is optional. Enter the amount in the paired asset (USDC unless you chose
another), or leave it at zero for no dev buy. The amount appears again in the final
review.

## Review, then create

1. **Open the review** — Once the form is valid, continue to the launch review.
2. **Check the details** — Verify the creator wallet, network, buy and sell tax, dev
   buy, allocation and links. Use "Back to details" to make a correction.
3. **Confirm the launch** — Choose "Create token" in the review. Keep the dialog open
   while it processes the launch and checks the token page.

If you switch wallets after opening the review, return to the form and review again
with the wallet you intend to use.

See also: [`04-launch-status.md`](04-launch-status.md)
